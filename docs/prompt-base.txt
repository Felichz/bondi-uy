Contexto General:
Estoy desarrollando una aplicación móvil en Flutter llamada "BondiUY". El objetivo es crear una versión simple y estética de Moovit para Montevideo, Uruguay. La funcionalidad principal del MVP incluye mostrar un mapa interactivo (Mapbox) con las paradas de ómnibus, permitir la interacción con ellas para ver qué líneas paran allí, y planificar un viaje simple (origen a destino) combinando caminatas y un tramo de ómnibus.

Objetivo Actual del Agente:
Continuar con el refinamiento de la interfaz de usuario y la experiencia general de la aplicación, e identificar próximas funcionalidades a desarrollar.

Estado Actual del Proyecto:
Mapa y Geocoding:
*   Se muestra un mapa de Montevideo usando `mapbox_maps_flutter`.
*   Los campos de Origen y Destino usan autocompletado con la API de Geocoding de Mapbox.
*   Al tocar una parada general (con zoom suficiente), se llama a la API de transporte de Montevideo para mostrar las líneas que pasan por ella en un BottomSheet.
*   La barra de escala del mapa de Mapbox ha sido ocultada.

Panel de Búsqueda Superior:
*   Inicia expandido, permitiendo al usuario ingresar Origen y Destino.
*   Una vez que se calcula una ruta exitosamente, este panel se colapsa automáticamente a una vista compacta.
*   La vista compacta muestra un resumen del origen y destino, y un botón "Modificar" que permite al usuario re-expandir el panel para cambiar la búsqueda.

Planificación de Ruta (Integración con OTP GraphQL):
*   Se utiliza OpenTripPlanner (OTP) v2.7.0 auto-hospedado localmente (puerto 8080) con datos GTFS de Montevideo y OSM.
*   Se integró exitosamente la aplicación Flutter con la API GraphQL del servidor OTP local usando la query `plan`.
*   Se utiliza el paquete `graphql_flutter` para las llamadas a la API.

Visualización de Ruta y Experiencia de Usuario (UX):
*   Los segmentos de la ruta (caminata y bus) se dibujan como `LineLayer` con estilos diferenciados (grosor, color) y un efecto de sombra.
*   Paradas Generales: Se cargan desde `assets/stops.geojson`. Se visualizan como `SymbolLayer` usando un ícono personalizado (`bus-icon` cargado desde `assets/icons/bus_icon.png`) y solo son visibles a nivel de zoom >= 14.0.
*   Paradas de Ruta: Las paradas de inicio y fin de los tramos de autobús del itinerario calculado se muestran como `SymbolLayer` separada, usando el mismo ícono `bus-icon` (ligeramente más grande).
*   "Wizard" de Ruta en Dos Pasos:
    1.  **Vista General**: Tras calcular la ruta, el mapa hace zoom para mostrar todo el recorrido con un estilo uniforme. Se muestra un mensaje "Este será tu recorrido completo" (integrado en la UI, no como SnackBar) y un botón "Iniciar Viaje".
    2.  **Navegación Detallada**: Al pulsar "Iniciar Viaje", el mapa se enfoca en el primer tramo, se aplica resaltado al tramo seleccionado (más opaco y grueso, los demás más tenues), y aparece la barra de previsualización de instrucciones inferior.
*   Barra de Previsualización de Instrucciones Inferior (Tras "Iniciar Viaje"):
    *   Muestra dinámicamente los detalles del tramo actualmente seleccionado (ícono de modo, descripción, distancia/duración).
    *   Incluye botones de navegación (flecha izquierda/derecha) para moverse rápidamente entre los tramos. Estos botones actualizan el mapa (zoom y resaltado) y la información en la barra.
    *   Tocar la sección central de esta barra expande un `BottomSheet` con la lista completa de instrucciones del viaje.
*   BottomSheet de Instrucciones (Expandible):
    *   Muestra la lista detallada de todos los tramos del viaje (origen, caminatas, buses, destino).
    *   Permite al usuario tocar un tramo para seleccionarlo, lo que actualiza el resaltado y el zoom en el mapa, y la información en la barra de previsualización inferior.
*   Indicadores de Carga: Se muestran indicadores visuales en el botón de búsqueda y sobre el mapa mientras se calcula la ruta.

Archivos Principales y Dependencias:
*   `lib/main.dart`: Contiene la UI principal, lógica de mapa, geocoding, cliente GraphQL, query, dibujado de ruta/paradas, BottomSheet de instrucciones, indicadores de carga, y la nueva lógica de UI/UX.
*   `pubspec.yaml`: Incluye `mapbox_maps_flutter`, `http`, `flutter_polyline_points`, `graphql_flutter`. Se declaró la carpeta `assets/icons/`.
*   `assets/`: Contiene `stops.geojson`.
*   `assets/icons/`: Contiene `bus_icon.png`.
*   Servidor OTP: Auto-hospedado localmente.
