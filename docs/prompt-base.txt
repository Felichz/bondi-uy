Contexto General:
Estoy desarrollando una aplicación móvil en Flutter llamada "BondiUY". El objetivo es crear una versión simple y estética de Moovit para Montevideo, Uruguay. La funcionalidad principal del MVP incluye mostrar un mapa interactivo (Mapbox) con las paradas de ómnibus, permitir la interacción con ellas para ver qué líneas paran allí, y planificar un viaje simple (origen a destino) combinando caminatas y un tramo de ómnibus.
Objetivo Actual del Agente:
Continuar con el desarrollo de las funcionalidades restantes del MVP, enfocándose ahora en la integración con OpenTripPlanner.
Estado Actual del Proyecto:
Mapa, Paradas y Geocoding:
*   Se muestra un mapa de Montevideo usando mapbox_maps_flutter.
*   Las paradas de ómnibus se cargan desde assets/stops.geojson y se visualizan como círculos rojos.
*   Al tocar una parada, se llama a la API de transporte de Montevideo para mostrar las líneas que pasan por ella en un BottomSheet.
*   Los campos de Origen y Destino usan autocompletado con la API de Geocoding de Mapbox.
Planificación de Ruta (Intento con OTP REST API):
*   Se decidió usar OpenTripPlanner (OTP) auto-hospedado para la planificación de rutas, utilizando los datos GTFS oficiales de Montevideo y datos de OpenStreetMap (uruguay-latest.osm.pbf).
*   Se ha iniciado exitosamente un servidor OTP v2.7.0 localmente en el puerto 8080 con los datos mencionados (`java -Xmx2G -jar otp-shaded-2.7.0.jar --build --serve .`).
*   Se intentó integrar la aplicación Flutter con la API REST del servidor OTP local (endpoint `/otp/routers/default/plan`).
*   **Bloqueo Actual:** Se obtiene un error persistente `HTTP 404 Not Found` al intentar acceder a la API REST del router `default` (`http://localhost:8080/otp/routers/default/` y sus sub-rutas), a pesar de que el servidor parece construir el grafo e iniciarse correctamente. Se intentó usar archivos `build-config.json` y `router-config.json` explícitos sin éxito para resolver el 404.
Archivos Principales y Dependencias:
*   `lib/main.dart`: Contiene la UI principal, lógica de mapa, geocoding y la llamada (actualmente fallida) a la API REST de OTP.
*   `pubspec.yaml`: Incluye `mapbox_maps_flutter`, `http`, `flutter_polyline_points`.
